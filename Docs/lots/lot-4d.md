# Lot 4d — Carte seule, saisie assistée de l'adresse, calques selon les aléas de l'adresse
**Livré.** A : carte réelle seule (plus de schéma, d'accord ni de bouton de retour), affichée dès qu'une adresse valide est en session, Leaflet chargé après le premier rendu ; carte pleine largeur (panneau à droite dès 1200 px), `score` et `equipements` dessous sans étirement ; information de confidentialité. B : combobox ARIA 1.2 (`adresse-assistee*.js`) sous les champs de l'accueil et du diagnostic, complétion IGN avec repli sur `search`, vérification à la validation. C : lecture des aléas (API Géorisques), cases dynamiques, mode de secours, parcours et confidentialité testés.
**Choix.** `index.html` charge aussi `diagnostic.json` (URL, seuils, types) ; textes de la saisie dupliqués dans `accueil.json` et `diagnostic.json` (un test les compare) ; `autocomplete="off"` sur les champs ; refus hors de France = « Adresse introuvable » ; en échec de vérification sur l'accueil, le message `nonVerifiee` est annoncé avant la navigation ; panneau de la carte : hauteur plancher persistante (anti-CLS).
